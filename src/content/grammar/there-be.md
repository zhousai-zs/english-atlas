## 规则与用法

中文的“有”至少对应英语两个动词。某人拥有，用 have：I have a book. 某处存在某物，用 there be：There is a book on the desk. there 在这里不是“那里”，它只是占着主语的位置，真正的主语是后面的名词。所以动词的单复数看那个名词，不看 there。

There is a bug. There are two bugs. There is some water. 否定和疑问像普通的 be：There isn’t a bug. Are there any questions? any 常出现在否定和疑问里。过去时是 there was、there were：There was a delay yesterday.

几个名词并列时，传统的教学规则是就近一致：There is a pen and two notebooks. There are two notebooks and a pen. 离 be 最近的名词决定形式。想写得最稳，就把复数名词放在前面并使用 are，或者拆成两句。

there be 后面可以接名词加地点、时间或分词：There is a man waiting outside. There are several jobs running. 不要说 There have a man. 也不要把 there be 和 have 叠成 There is have. 如果主语是人，拥有关系就回到 have：The desk has four legs. 这句强调桌子“拥有”四条腿，和 There are four legs 的存在句不是同一个意思。
