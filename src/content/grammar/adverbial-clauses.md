## 规则与用法

状语从句修饰整个谓语或整句话，说明时间、地点、原因、条件、让步、目的、结果或方式。它由从属连词引导，可以放在主句前面。放在前面时，后面通常加逗号：When she arrives, I will call you.

时间连词 when、while、before、after、until、as soon as 如果谈的是将来，从句用一般现在时，不用 will。while 强调一段同时发生的事，until 表示持续到某个动作出现。原因里 because 最直接，回答 why。since 和 as 常常表示双方已知的原因，语气比 because 轻：Since you are here, let’s start.

条件用 if。unless 的意思接近 if ... not：Unless you save, you will lose it. 等于 If you do not save... 但当主句是否定句，或者条件本身是否定的，unless 不一定能机械替换，初学先用 if not 最安全。让步用 although、though、even though。它们已经包含“虽然”，主句不再加 but。

目的用 so that，从句里常有 can、could、will、would：She left early so that she could catch the train. 结果用 so ... that 或 such ... that。so 后面是形容词或副词：so long、so carefully。such 后面是名词短语：such a long log、such clear code。不要写成 so a long log。in order that 比 so that 更正式，意思同为目的。
